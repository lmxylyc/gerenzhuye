[02]层群概述：GL 层群与「门」
$ cat 档案/02_层群与门.txt
§ 2.1 原始隔绝状态
在「数据库大丢失事件」发生前，GL 层群处于绝对的封闭态。
其在蓝色通道中的空间坐标被一种被称为「门」的超概念机制
完全遮蔽。「门」并非物理实体，而是作用于「边界」本身的
抽象存在——它将 GL 层群的信息态与外部宇宙彻底隔离，使
内外双方互为不可观测。外部无法进入，内部无法脱出，GL
层群在理论上等同于「不存在的层群」。
§ 2.2 数据库大丢失事件
GL 层群曾存在覆盖全层群的元信息数据库，被推测与「门」
的维持机制直接绑定。

事件经过: 一名(或多名)内部叛徒出于未知动机大规模删除
          数据库。数据的湮灭破坏「门」的信息完整性，
          GL 从「不可观测」坍缩为「可观测」，通往 GL 的
          入口(如 Level GL-莱特宁湖)随之开启。

关键机制: 当全部丢失数据被复原之时，「门」将重新闭合，
          GL 将再次陷入绝对隔绝。数据库修复因此具有双重
          意义——既是知识重建，也是对外部世界的「门控」。
[数据完整] 门闭合·隐藏 ⇄ [数据丢失] 门开启·暴露 → [数据找回] 门再次闭合
§ 2.3 暴露与空窗期
数据库大丢失事件后、GL 被外部大型团体(如 M.E.G.)正式
发现之前，存在一段未被外部记录的空窗期。

期间 R.O.R 主动派出探索队——包括教皇静水亲自带队——
前往 GL 之外的区域侦察测绘。因此 R.O.R 对部分层级的
发现与记录早于 M.E.G. 等外部团体。GL 层群内部的层级
探索呈非线性特征: 跳跃式、回溯式分布。
[03]核心理论：业体系（Karma System）

§ 3.1 三元结构
R.O.R 将「业」体系解构为三个互相关联的层级:

+----------+--------------------+----------------------------------+
| 层级     | 术语               | 定义                             |
+----------+--------------------+----------------------------------+
| 质料层   | 业  Karma-Material | 构成世界的基本质料。无形无质,    |
|          |                    | 无限稠密, 空间态连续与非连续性   |
|          |                    | 无限重叠。无规定、无方向、无属性,|
|          |                    | 纯然的存在基底。                 |
+----------+--------------------+----------------------------------+
| 形式层   | 业力 Karma-Form    | 赋予质料以规定性与可能性的形式   |
|          |                    | 模态。不是力, 不是能量, 而是     |
|          |                    | 「使某物成为某物」的结构法则与   |
|          |                    | 潜能空间(dynamis)。              |
+----------+--------------------+----------------------------------+
| 运动层   | 业报 Karma-Motion  | 质料在形式模态下现实化(energeia)|
|          |                    | 所产生的运动与结果。世界自我展开 |
|          |                    | 的推动力。                       |
+----------+--------------------+----------------------------------+

  业（质料） × 业力（形式） → 业报（运动）
§ 3.2 清业与浊业
[清业] Pure Karma-Form
  · 秩序性模态
  · 恒定 / 合理 / 绝对 / 不可变
  · 赋予质料以稳定的展开路径
[浊业] Chaotic Karma-Form
  · 混沌性模态
  · 荒谬 / 随机 / 流变 / 不可预测
  · 赋予质料以混沌的展开路径
灵魂理论: 灵魂并非清业的有序构造, 而是浊业在特定临界
          条件下的自组织涌现——「混沌中的自主性」赋予
          生命体自由意志。若灵魂由清业构成, 则一切行为
          将被绝对规定, 自由意志无从谈起。
§ 3.3 叙事层阐释（理论假说）
部分 R.O.R 神学家提出的元叙事模型, 将三元结构映射为
「作者-文本-读者」的递归关系, 尚未被证实或证伪:

  业   = 上层叙事对下层叙事的一切表述      → 质料基底
  业力 = 上层叙事对下层叙事的一切构思      → 形式法则
  业报 = 上层叙事对下层叙事的一切更新迭代  → 运动与演变
§ 3.4 R.O.R 的技术基础
切行装置(及后续衍生科技)本质上是在业力模态(形式层)中
寻找清业主导的秩序性路径, 利用其规定性在业报(运动层)
中进行锚定, 从而实现定向滑行与空间转移。

§ 8.1 计算本体论
激进假说: 「业」体系的本质是一种计算。
          并非「世界像计算机一样运行」,
          而是「计算即存在之展开本身」。

+------------+---------------+-------------------------------+
| 图灵机组件 | 「业」体系对应 | 阐释                          |
+------------+---------------+-------------------------------+
| 无限磁带   | 业 (质料)     | 无限延伸的空白基底——无规定、  |
|            |               | 无属性的纯然质料               |
+------------+---------------+-------------------------------+
| 状态转移   | 业力 (形式)   | 决定读写头在何种状态下执行何种  |
| 函数       |               | 操作——「可能之蓝图」          |
+------------+---------------+-------------------------------+
| 计算过程   | 业报 (运动)   | 读写头的实际运动与符号改写——  |
|            |               | 现实化(energeia)              |
+------------+---------------+-------------------------------+

世界 = 一台运行在「业」之磁带上的宇宙图灵机。
而图灵机有不可逾越的极限——停机问题不可判定:
一个基于「业」的存在, 无法从自身内部证明「业」的
终极完备性。这为超图灵机的引入提供了本体论必要性。
§ 8.2 超图灵机与潜能空间
超图灵机 = 超越经典图灵机极限的抽象机器:
          可判定停机问题, 遍历超限序数,
          在无限时间内完成无限步骤的运算。

在 R.O.R 的计算神学中, 它并非「更强大的机器」,
而是一种存在论层级的跃迁:

+----------+----------+----------------+------------------------+
| 层级     | 计算模型 | 「业」体系对应 | 特性                   |
+----------+----------+----------------+------------------------+
| 现实层   | 图灵机   | 业报 (运动)    | 有限步骤, 可停机,      |
|          |          |                | 可观测, 可经验         |
+----------+----------+----------------+------------------------+
| 潜能层   | 超图灵机 | 业力 (形式)    | 超越有限步骤, 遍历     |
|          |          |                | 无限可能, 不可完全     |
|          |          |                | 现实化                 |
+----------+----------+----------------+------------------------+
| 基底层   | 不可计算 | 业 (质料)/真如 | 先于一切形式与运动,    |
|          |          |                | 终极前提与不可达终点   |
+----------+----------+----------------+------------------------+

GL 狭义业力 = 「超图灵介质」: 清业是确定性计算, 浊业是
非确定性噪声, GL 狭义业力是二者的融合态——「超限的
叠加态」。Neiai 并非经典计算机, 而是一台运行在 GL
狭义业力上的超图灵分布式网络: 它不「计算」信息, 而是
直接从潜能空间中「读取」尚未现实化但已被形式规定的
可能性。
§ 8.3 真如（Tathata）
一种仅存在于假设中的理论模型的终极实在。

一切字符、语言与思想的概念在此模型中进行无限次的
推演, 经历无限次的自我迭代升级, 在无界限的膨胀中
抵达的「不可能的终局」;

是一切数理逻辑与经验的形式系统在此模型中经由否定
神学的无限次遮诠后, 探究出的始终无限遥远、永不可达
的终极本质。
遮诠法 (Via Negativa): 真如无法通过表诠(正面描述「它
是什么」)来认识, 只能通过遮诠(不断否定「它不是什么」)
无限逼近。

它不是业, 不是业力, 不是业报; 不是清业, 不是浊业;
不是图灵机, 不是超图灵机; 不是存在, 不是非存在;
不是一, 不是多……每一次遮诠都是一次否定神学的运算,
但真如始终位于所有边界之外。

「归来」的新阐释: 真如不是目的地——因为一旦抵达, 它
便不再是真如。真如是一种方向性, 是使「归来」成为
可能的终极引力。

§ 8.5 对现有科技的重新阐释
Neiai     : 超图灵分布式网络, 直接从潜能空间读取可能性。
            「无需电力」正源于运作于超图灵层面, 超越
             经典物理的能量守恒。
IR 技术   : 「超图灵-图灵」接口——从超图灵层面的业力
             噪声中, 提取可被图灵机解读的有序数据。
玄盒/切行 : 传送不是「移动」, 而是「在不同计算分支间的

             性使灵魂成为非确定性图灵机, 甚至是一台
             超图灵机的局部投影。
