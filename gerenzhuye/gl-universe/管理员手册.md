# GL 层群宇宙 · 管理员账号注册讲解手册

本手册讲解：如何获得站长（管理员）账号、登录、以及使用管理后台。
适用对象：站长本人、受委托的管理员、以及需要把作者放行的操作者。

> 站点：https://sh.vvplan.cn/gerenzhuye/gl-universe/
> 创作端口：https://sh.vvplan.cn/gerenzhuye/gl-universe/editor/

---

## 一、获得管理员账号的三种方式

管理员账号（role = admin）有以下三种获得途径，任选其一：

### 方式一：首次初始化（站长创建第一个账号）

**适用**：站点刚部署、还没有任何账号时。打开创作端口会看到「站点尚未创建站长账号」区块。

操作步骤：
1. 打开创作端口，找到 **站长初始化** 表单（无需登录）。
2. 依次填写：
   - **设立密钥**：自己设定一个密钥（如 `GL-FOUNDER-2026`），**务必记住**。它用于今后通过注册成为站长。
   - **写入令牌**：GitHub 的 Fine-grained token（需 `Contents: Read and write` + `Actions: Read and write`，仅勾选本仓库）。
   - **站长用户名 / 昵称 / 密码**：你的账号信息。
3. 点击 **「初始化并创建站长账号」**，即自动完成：写入站点配置 + 创建 admin 账号 + 自动登录。

> 注意：设立密钥同时会被用作「写作口令」（加密存储令牌的口令）。初始化后建议在管理后台把设立密钥清空，避免他人用密钥注册成站长。

### 方式二：用设立密钥注册成为站长

**适用**：站点已有其他站长，站长把设立密钥告知你后，你用它注册。

操作步骤：
1. 打开创作端口 → 切到 **注册** 页签。
2. 填写用户名、昵称、密码，并在 **设立密钥** 栏填入站长告知的密钥。
3. 提交后如果密钥正确且站点尚无站长，将**直接成为 admin**；否则注册为普通作者（pending），需站长批准。

> 安全提醒：设立密钥相当于「站长钥匙」，只应分享给可信的人。用完后请站长在管理后台清空。

### 方式三：由现有站长在后台直接添加

**适用**：站长想把某人直接提升为管理员（对方可先普通注册或已有账号）。

操作步骤：
1. 站长登录 → ⚙ **管理后台** → **用户管理**。
2. 找到目标账号，把角色从「作者」改为 **站长**，保存即可。

## 二、登录

1. 打开创作端口 → 输入 **用户名 + 密码** → 点登录。
2. 登录成功后浏览器会记住会话（打开页面即自动登录，无需重复输入密码）。
3. 顶栏显示你的昵称与角色徽标 `[admin]`，右侧出现 **⚙ 按钮**（管理后台入口）。
4. 点击顶栏昵称可进入「我的资料」，修改昵称、简介。

> 忘记密码：由其他站长在管理后台 → 用户管理 → **重置密码** 帮你设置新密码。

## 三、管理后台功能

登录后点击顶栏 **⚙** 进入管理后台，共三个区块：

### 1. 待审核注册（放行新作者）

- 新作者注册后状态为 `pending`，出现在「待审核注册」列表。
- 点 **批准** → 该账号成为作者，可以开始创作。
- 点 **拒绝** → 删除该注册记录。

### 2. 用户管理（账号维护）

每个用户一行，可执行：
- **改角色**：作者 ⇄ 站长（下拉选择）。
- **重置密码**：为新密码（弹窗输入，至少 6 位）。
- **删除用户**：移除账号（其已发布页面保留）。

### 3. 系统配置（站点设置）

| 项目 | 说明 |
|------|------|
| 站点名称 | 显示在页面标题/页脚 |
| 开放注册 | 关闭后新用户无法注册 |
| 写入令牌 | GitHub 令牌（保存时以写作口令加密存储） |
| 写作口令 | 加密/解锁令牌的口令，作者设备上输入一次即可保存 |
| 设立密钥 | 注册站长用；用完请清空 |
| 仓库 / 路径 | GitHub 仓库与内容目录（一般无需改动） |

修改后点 **保存配置**，配置会写入仓库并触发自动部署。

## 四、发布流程（管理员视角）

1. 作者在创作端口注册 → 你在后台 **批准**。
2. 作者新建「档案卡片」或「长文档」→ 填标题与内容 → **保存**。
3. 保存动作自动：提交到仓库 → GitHub Pages 自动构建部署（约 2-4 分钟）。
4. 上线后：
   - 独立页面：`https://sh.vvplan.cn/gerenzhuye/gl-universe/w/<标题>.html`
   - 档案库：`https://sh.vvplan.cn/gerenzhuye/gl-universe/archive.html` 自动收录

> 若作者保存后页面暂时 404，属正常（部署中）；若超过 10 分钟仍 404，检查 Cloudflare 缓存（清一次缓存即可）。

## 五、安全须知

- **设立密钥 / 写作口令** 等于管理权钥匙，只发给可信的人；用后及时清空/修改。
- **写入令牌** 以加密形式存放于 `content/site-config.json`，作者浏览器输入写作口令后自动解锁使用；令牌仅限本站仓库。
- 账号密码以「加盐 SHA-256」存储，不存明文。
- 管理员离职时：删除其账号，并在后台 **修改写作口令**（重新加密令牌）。
- 若怀疑令牌泄露：在 GitHub 上作废该令牌 → 重新生成 → 在管理后台更新写入令牌并保存。

## 六、常见问题

**Q1：打开创作端口提示「站点尚未创建站长账号」？**
说明还没有 admin。按「方式一」完成站长初始化。

**Q2：注册时说「站点已有站长账号，设立密钥仅用于首次创建」？**
说明已存在 admin，直接普通注册，让站长在后台批准即可（或让站长告知新的设立密钥——需先在系统配置里设置）。

**Q3：作者保存时提示输入「写作口令」？**
这是正常解锁流程，输入站长设置的写作口令（默认等于设立密钥，如 `gl-2026`）即可，只需在该设备输入一次。

**Q4：保存提示「令牌权限不足」？**
去 GitHub 检查令牌权限：需 `Contents: Read and write` 和 `Actions: Read and write`，且仓库选择正确。

**Q5：页面保存成功但访问 404？**
等待 2-4 分钟构建部署；仍 404 则清一次 Cloudflare 缓存（sh.vvplan.cn 的 CDN 缓存）。
